# netcheck

Единый инструмент для диагностики и обхода интернет-блокировок.

## Идея

Большинство инструментов обхода блокировок (zapret, spoofDPI) требуют ручной настройки и технических знаний. `netcheck` делает два шага автоматически:

1. **Диагностирует** — определяет, что именно заблокировано: DNS, SNI, IP.
2. **Решает** — применяет нужную стратегию обхода и проверяет результат.

## Возможности

### ✅ Реализовано

- **Диагностика DNS** — сравнение обычного DNS и DoH, определение подмены.
- **Диагностика TLS** — анализ этапа обрыва: timeout, reset, EOF, сертификат.
- **Диагностика DoH** — резолв через Cloudflare, IPv4 + IPv6.
- **Автоматический вывод** — инструмент сам определяет тип блокировки.
- **HTTP CONNECT прокси** — с DoH-резолвером и двусторонним проксированием.

### 🚧 В разработке

- **Фрагментация ClientHello** — обход SNI-фильтрации.
- **Веб-интерфейс** — управление через браузер.
- **Кроссплатформенность** — Windows, macOS.

## Стек

- Go 1.25+
- gorilla/mux (роутинг)
- go-doh-client (DNS-over-HTTPS)
- crypto/tls (анализ TLS)
- net (TCP, HTTP CONNECT)

## Использование

### Диагностика

```bash
go run cmd/netcheck/main.go diagnose rutracker.org
```

Вывод:
```
✅ Резолвится в: [...]
⚠️ DPI: соединение зависло (timeout).
✅ DoH резолвит в: [...]
📋 Итог: SNI-фильтрация. Рекомендуется фрагментация ClientHello.
```

### Прокси

```bash
go run cmd/netcheck/main.go serve
```

Прокси поднимется на `127.0.0.1:8080`. Настройте браузер на этот прокси.
