# netcheck

Единый инструмент для диагностики и обхода интернет-блокировок.

## Идея

Большинство инструментов обхода блокировок (zapret, spoofDPI) требуют ручной настройки и технических знаний. `netcheck` делает два шага автоматически:

1. **Диагностирует** — определяет, что именно заблокировано: DNS, SNI, IP.
2. **Решает** — применяет нужную стратегию обхода и проверяет результат.

## Возможности (в разработке)

- 🔍 **Диагностика**: DNS, TLS, SNI, HTTP
- 🛡️ **Обход**: фрагментация TLS ClientHello, DNS-over-HTTPS, domain fronting
- 🌐 **Локальный прокси**: настройка браузера/системы в один клик
- 🖥️ **Веб-интерфейс**: понятный даже школьнику
- 💾 **Конфиг**: запоминает рабочие стратегии для твоего провайдера

## Стек

- Go 1.25+
- gopacket (raw sockets для фрагментации)
- miekg/dns (DNS-запросы)
- crypto/tls (анализ TLS)
- net/http (веб-интерфейс и прокси)
